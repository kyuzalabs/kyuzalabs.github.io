🖥️ Server Health Dashboard

PythonPantau CPU/RAM/disk/uptime + status service — bisa dipakai di server siapa pun.

ℹ️ Apa ini & cara pakai

Satu file Python tanpa dependency yang baca /proc + systemctl, terus tampil jadi dashboard web live.

Cara pakai dasar:
python3 server_dashboard.py
Lalu buka http://localhost:8090 di browser.
Mantau service kamu sendiri (ganti nama service-nya):
python3 server_dashboard.py --services "bot-ku.service,nginx.service"
Nama service bisa dilihat pakai: systemctl --type=service
