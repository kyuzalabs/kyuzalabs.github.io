# Document & Warranty Wallet

Dompet digital untuk dokumen rumah tangga — simpan tanggal expired (garansi, pajak, paspor, asuransi) dan dipantau statusnya.

**Cara pakai:** tambah dokumen + tanggal expired → sistem otomatis tandai status: 🟢 aman, 🟡 <30 hari lagi, 🔴 expired.

**Fitur:**
- Kategori dokumen (garansi, pajak, paspor, STNK, asuransi, kontrak, langganan)
- Hitung sisa hari otomatis + badge peringatan
- Urutkan dokumen yang paling dekat expired
- Data tersimpan lokal di perangkat

**Stack:** HTML · Vanilla JS · localStorage — tanpa dependency, bisa di-host gratis.

> Kelanjutan alami dari AI Daily Assistant (reminder) — bisa dihubungkan ke notifikasi Telegram di versi berikutnya.
