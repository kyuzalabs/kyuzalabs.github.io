🐍 Mint Radar

PythonScanner mint/airdrop aktif dari katalog on-chain Agent ID (±1.000 proyek).

ℹ️ Apa ini & cara pakai

Script Python yang jalan di terminal (bukan di browser). Dia download katalog proyek, terus filter mana yang free mint & risiko rendah — biar kamu nggak buang gas buat mint yang nggak ada isinya.

Butuh Python 3 (tanpa install apa-apa, pure stdlib). Jalankan perintah ini:
python3 mint_radar.py python3 mint_radar.py --free python3 mint_radar.py --free --max-risk low python3 mint_radar.py --json

• --free = cuma yang gratis/gas doang · --max-risk low = buang yang risiko medium/high · --json = output buat di-connect ke bot lain.
