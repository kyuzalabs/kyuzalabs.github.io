# Crypto Calculator

Kalkulator crypto **100% offline** — dua alat dalam satu halaman.

**Alat:**
1. **DCA (Dollar-Cost Averaging)** — hitung harga rata-rata dari beberapa pembelian
2. **Profit / Loss** — hitung untung/rugi (per unit + total) dari harga beli vs jual

**Cara pakai:** buka `index.html`, pilih tab, isi angka. Semua hitung otomatis saat mengetik.

**Stack:** HTML · Vanilla JS — tanpa dependency, jalan offline, bisa di-host gratis (GitHub Pages).

⚠️ Alat bantu estimasi, bukan nasihat keuangan.
