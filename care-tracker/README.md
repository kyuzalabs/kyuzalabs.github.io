# Baby & Pet Care Tracker

Pencatat aktivitas harian untuk bayi atau hewan peliharaan — log menyusu/tidur/popok (bayi) atau makan/obat/vaksin (hewan), lengkap dengan ringkasan harian.

**Cara pakai:** pilih mode (Bayi / Hewan) → klik aktivitas untuk mencatat → lihat ringkasan harian + riwayat.

**Fitur:**
- Dua mode: 👶 Bayi & 🐾 Hewan
- One-tap logging dengan timestamp otomatis
- Ringkasan jumlah aktivitas hari ini
- Riwayat aktivitas (20 terakhir)
- Data tersimpan lokal di perangkat

**Stack:** HTML · Vanilla JS · localStorage — tanpa dependency, bisa di-host gratis. Cocok juga diakses dari HP.

> Bisa dikembangkan jadi multi-user (suami-istri sharing) dengan backend di versi lanjut.
