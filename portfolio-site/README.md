# Portfolio Site

Halaman profil / link-in-bio personal — ngerangkum identitas, skill, dan semua project dalam satu landing page.

**Cara pakai:** buka `index.html` di browser, atau host gratis di GitHub Pages / Vercel.

**Isi halaman:**
- Nama, role, bio singkat
- Link sosial media (X, Telegram, GitHub)
- Kartu project (semua repo)
- Daftar skill

**Stack:** HTML · CSS murni — tanpa framework, ringan & cepat.
