# Emergency Info Card QR

Kartu darurat digital (ICE — In Case of Emergency) dengan QR code yang bisa diprint & ditempel.

**Cara pakai:** isi data darurat (nama, gol darah, alergi, obat, kontak) → klik "Buat QR Card" → muncul kartu + QR code. Print kartunya, tempel di dompet/tas/kunci. Saat darurat, siapa pun bisa scan QR-nya untuk langsung lihat info pentingmu.

**Fitur:**
- QR code berisi info darurat (bisa dibaca langsung saat di-scan, tanpa internet)
- Data tersimpan lokal di perangkat (privacy terjaga)
- Format kartu yang mudah diprint

**Stack:** HTML · Vanilla JS · localStorage · QR API (qrserver.com) — tanpa dependency, bisa di-host gratis.
